Tu IA, explicada sin tecnicismosYour AI, explained without jargon

Minuta no trae una IA propia: usa la que tú ya tienes, con tu cuenta. Para eso necesita una pequeña herramienta que se instala una sola vez. Aquí te explicamos qué es, cuál elegir y cómo dejarla lista en unos cinco minutos. No necesitas saber programar.Minuta doesn't bring its own AI: it uses the one you already have, with your account. For that it needs a small tool you install just once. Here's what it is, which one to pick and how to set it up in about five minutes. No coding required.

¿Qué son Claude Code, Codex y Antigravity CLI?What are Claude Code, Codex and Antigravity CLI?

Seguro conoces Claude, ChatGPT o Gemini como un chat en el navegador o en el teléfono. Estas herramientas son el mismo asistente, en versión para el computador: en vez de una página web, funcionan desde la terminal (esa ventana donde se escriben comandos). Gracias a eso, Minuta puede pedirle a tu IA que escriba las notas en segundo plano, sin abrir nada.You probably know Claude, ChatGPT or Gemini as a chat in your browser or phone. These tools are the same assistant, in a version for your computer: instead of a web page, they run from the terminal (that window where you type commands). That lets Minuta ask your AI to write your notes in the background, without opening anything.

Claude Code

Para quienes usan ClaudeFor Claude users

  1. Ten tu cuenta listaHave your account ready

    Necesitas Claude Pro o Max, o una cuenta de trabajo (Team o Enterprise). El plan gratis de Claude no incluye Claude Code.You need Claude Pro or Max, or a work account (Team or Enterprise). Claude's free plan doesn't include Claude Code.

  2. InstálaloInstall it

    curl -fsSL https://claude.ai/install.sh | bash
    irm https://claude.ai/install.ps1 | iex
    Otras formas de instalarloOther ways to install it
    • Con Homebrew:With Homebrew: brew install --cask claude-code
    • Con WinGet:With WinGet: winget install Anthropic.ClaudeCode
    • Con npm (necesita Node.js):With npm (needs Node.js): npm install -g @anthropic-ai/claude-code

  3. Inicia sesiónSign in

    Cierra la terminal, ábrela de nuevo y escribe claude + Enter. Se abrirá tu navegador para entrar con tu cuenta de Claude. Cuando termine, vuelve a la terminal y sal con Ctrl + C dos veces.Close the terminal, open it again and type claude + Enter. Your browser will open so you can sign in with your Claude account. When it's done, go back to the terminal and exit with Ctrl + C twice.

    claude

  4. Comprueba que quedó bienCheck it worked

    Debería mostrar un número de versión. Si algo no anda, claude doctor te dice qué revisar.It should print a version number. If something's off, claude doctor tells you what to check.

  5. Listo: vuelve a MinutaDone: go back to Minuta

¿Qué recibe tu IA?What does your AI receive?

Solo el texto de la reunión (la transcripción) y las instrucciones para escribir las notas. Nunca el audio. Va directo de tu computador a tu proveedor, con tu cuenta, igual que si lo pegaras en su chat.Only the meeting text (the transcript) and the instructions to write the notes. Never the audio. It goes straight from your computer to your provider, with your account, just as if you pasted it into their chat.

Un consejo: revisa la configuración de privacidad de tu cuenta de IA (por ejemplo, si permites que usen tus conversaciones para entrenar sus modelos) y elige lo que te acomode. Y recuerda avisar a los demás que estás grabando.A tip: check your AI account's privacy settings (for example, whether your conversations may be used to train their models) and choose what suits you. And remember to tell others you're recording.

Si algo no funcionaIf something doesn't work

Dice «command not found» o «no se reconoce como comando»It says “command not found” or “is not recognized”
  • Cierra la terminal y ábrela de nuevo: la terminal que estaba abierta no ve lo recién instalado.Close the terminal and open it again: the one that was open can't see what you just installed.
  • Si el instalador mostró un mensaje para agregar una carpeta (por ejemplo ~/.local/bin) a tu PATH, copia y ejecuta el comando que te indicó.If the installer showed a message about adding a folder (for example ~/.local/bin) to your PATH, copy and run the command it showed.
  • Igual prueba en Minuta: busca en las carpetas habituales, así que a veces la encuentra aunque la terminal no. Toca Ya la instalé.Try in Minuta anyway: it looks in the usual folders, so it sometimes finds it even when the terminal doesn't. Click I installed it.
Minuta dice que no has iniciado sesiónMinuta says you're not signed in

Abre la terminal, escribe el nombre de tu IA (claude, codex o agy -p "hola") y completa el inicio de sesión en el navegador. Después vuelve a tocar Probar.Open the terminal, type your AI's name (claude, codex or agy -p "hello") and finish signing in in the browser. Then click Test again.

Windows dice que la ejecución de scripts está deshabilitadaWindows says running scripts is disabled

Antepón powershell -ExecutionPolicy ByPass -c y pon el comando entre comillas, así: powershell -ExecutionPolicy ByPass -c "irm https://claude.ai/install.ps1 | iex". Solo afecta a ese comando.Prefix it with powershell -ExecutionPolicy ByPass -c and put the command in quotes, like this: powershell -ExecutionPolicy ByPass -c "irm https://claude.ai/install.ps1 | iex". It only affects that command.

Usé npm y salió un error de permisos (EACCES)I used npm and got a permissions error (EACCES)

Usa mejor el instalador de un comando de arriba: no necesita Node.js ni permisos de administrador. Evita sudo npm install.Use the one-command installer above instead: it needs neither Node.js nor admin rights. Avoid sudo npm install.

Funciona, pero se acabó mi límite de usoIt works, but I ran out of usage

Cada proveedor tiene límites según tu plan. Espera a que se renueven o cambia de IA en Minuta: Preferencias → abrir el asistente de bienvenida → Tu IA.Each provider has limits based on your plan. Wait for them to reset or switch AI in Minuta: Preferences → open the welcome assistant → Your AI.

Mi empresa no me deja instalar programasMy company doesn't let me install software

Estos instaladores no piden permisos de administrador, pero algunas empresas los bloquean igual. Pregúntale a tu equipo de TI, o instala Minuta y tu IA en un computador personal.These installers don't ask for admin rights, but some companies block them anyway. Ask your IT team, or install Minuta and your AI on a personal computer.
