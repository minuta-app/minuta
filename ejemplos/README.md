# Ejemplos: haz lo que quieras con tus notas

Tus notas de Minuta son Markdown en tu carpeta y en tu Git ([formato](../README.md#formato-de-las-notas)). Estos ejemplos son
puntos de partida: cópialos, adáptalos y, si armas algo útil, compártelo en
[Discussions → Show and tell](https://github.com/minuta-app/minuta/discussions/categories/muestra-lo-que-armaste).

| Ejemplo | Qué hace |
|---|---|
| [`compromisos_abiertos.py`](compromisos_abiertos.py) | Lista tus compromisos sin marcar de todas las reuniones, por fecha, o los exporta a CSV para tu planilla o gestor de tareas. |
| [`reuniones_a_csv.py`](reuniones_a_csv.py) | Todas tus reuniones en una planilla (CSV), una fila por reunión: fecha, tipo, título, duración, % de habla, participantes y puntajes. |

¿Tienes otro? Abre un pull request con tu script en esta carpeta (solo biblioteca estándar, con datos ficticios en los ejemplos).
